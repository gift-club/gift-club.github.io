# gift-club.github.io

The home page of [gift-club.github.io](https://gift-club.github.io/) in nine languages, the `robots.txt` that lists every project's sitemap, and the shared 404 page.

```bash
node scripts/build-site.mjs   # writes docs/
```

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, folder `/docs`.

Projects: [Telegram Gifts & Stars Dataset](https://github.com/gift-club/telegram-gifts-dataset) · [Telegram Stars calculator](https://github.com/gift-club/telegram-stars-calculator) · [Provably fair verifier](https://github.com/gift-club/provably-fair-verifier). Made by [Gift Club](https://giftclub.app/).
